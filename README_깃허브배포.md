# 무역영어 CBT — iPhone PWA / GitHub Pages

## 빠른 배포
1. GitHub에서 새 **Public** repository 생성 (예: `trade-english-cbt`).
2. 이 ZIP을 **압축 해제하고 내부 파일과 폴더 자체**를 저장소 최상위 경로에 업로드합니다. ZIP 파일 하나만 올리지 마세요.
3. `Settings` → `Pages` → `Build and deployment` → `Source: Deploy from a branch` → `main / (root)` → `Save`.
4. `https://사용자명.github.io/trade-english-cbt/` 접속 후 아이폰 Safari의 **공유 → 홈 화면에 추가**를 누릅니다.

## 네트워크 및 오프라인
- 최초 접속은 인터넷 연결이 필요합니다. 처음 접속 시 `index.html`, `app.js`, `style.css`, 전체 `data.js` 및 앱 아이콘이 캐시됩니다.
- 시험 본문과 보기는 오프라인으로 실행할 수 있으나 원본 PDF 및 검수 이미지 등 큰 파일은 **열어 본 것만** 추가로 캐시되므로 최초 열람 시 네트워크가 필요합니다.
- iOS의 저장공간 정리, Safari 웹사이트 데이터 삭제, 앱 재설치 등으로 저장된 오프라인 자료와 풀이 기록이 사라질 수 있습니다. '풀이 기록 내보내기'를 주기적으로 사용하세요.
- 새 버전 게시 후에는 앱을 온라인 상태에서 새로 열어 캐시 갱신을 허용하세요.

## 주의: 공개 배포 및 저작권
- GitHub Pages는 일반적으로 공개 웹사이트입니다. 저장소를 비공개로 설정하더라도 사이트가 공개될 수 있습니다. 특히 무료 플랜에서는 공개 저장소를 기준으로 안내합니다.
- 기출문제·정답·PDF 원본을 업로드하기 전에 대한상공회의소 등 권리자의 복제/공중송신 허용 범위를 확인하세요. **개인 학습 목적도 공개 웹 배포 권한을 자동으로 부여하지 않습니다.**
- 외부 공개가 허용되지 않는 경우에는 GitHub Pages 배포를 하지 말고, 접근 제어가 되는 별도 호스팅이나 로컬 실행을 선택하세요.

- Safari 실제 기기에서의 설치·오프라인 동작은 별도 현장 검증이 필요합니다.
